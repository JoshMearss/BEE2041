## Introduction
This repository contains the code and documentation for the BEE2041 assignment.
The project focuses on making a data driven blog post using the skills learned 
on the course. The blog post is about the impact of weather on the outcome of 
football matches in the English Premier League (EPL).

## Repository Structure
The repository is structured as follows:

├── README##
├── Data
├── Outputs
├── Source Code
├── blog.txt

All data is contained in the data sub-directory, all source code is contained in 
Source Code sub-directory, and all graphs are in the output file.  

## Runnign instructions
The code is written in Python 3.8 and requires the following libraries:
- pandas
- numpy
- matplotlib

To get the code running, chnage the file directories in all source code files to 
the correct path. All of the code files should be able to run individually, how-
ever, the Keppers.ipynb file must be run in order as there was minor issues cre-
ating the Keeper_Temperature.csv file.
